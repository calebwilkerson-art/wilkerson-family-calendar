Sharing

This calendar is live. Send the link and anyone who opens it sees the same schedule, and can add or change things.

Not shared yet. Changes are saved on this device only. To make it live for the whole family, connect a free Firebase database (takes about five minutes, once).

  1. Go to console.firebase.google.com and add a project (any name, turn Analytics off).
  2. In the left menu choose Build › Realtime Database › Create database. Pick the US region and Start in locked mode.
  3. Open the Rules tab, replace everything with the rules below, then Publish.
  4. Back on the Data tab, copy the database URL shown at the top (it ends in firebaseio.com or firebasedatabase.app) and paste it here.
{
  "rules": {
    "$calendar": {
      ".read": true,
      ".write": true
    }
  }
}

Whatever is on this device now (including any events you've added) becomes the shared starting point.
